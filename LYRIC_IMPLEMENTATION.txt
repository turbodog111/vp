LOCAL EDITING
Open VP, select a recording, and choose Lyrics (or Settings > Lyric studio).
Load prepared text populates an EMPTY draft for the seven recordings above.
It does not overwrite an existing draft or change published lyric files.
For new material, paste one phrase per line in the appropriate language columns.
Blank lines are ignored. All supplied columns must have equal line counts.
English songs only display the English column. Japanese songs use romaji and
English, with optional Japanese script. Freefall uses Chinese/pinyin/English.
Line numbers are automatic. Enter seconds or mm:ss.xxx in In/Out fields, or
use Mark in/Mark out while listening. Use Seek to review a line with the existing
player. The editor never creates a second audio player or changes playback rate.
Draft changes save on blur/change in this browser. A storage failure is visible;
Export draft remains available. Export/Import transfers the exact recording's
draft between Macs. This is not cloud sync.
Preview local draft affects only this browser. FX for supported songs must also
be enabled. Untimed/invalid drafts cannot become active lyrics. Now Playing
returns to the original graphics with the local lyric display above them.

DISPLAY CONTRACT
One current phrase, with English prominent and native/romanized text subordinate.
Whole words change solid color when word timings are supplied; no per-letter
gradients, constant-speed fill, or simulated timing based on character count.
Without word timings, the entire phrase displays for its measured interval.
Line end is exclusive: text disappears at end and stays absent during silence.
The overlay never intercepts controls. Original graphics and audio remain.
Published lyric displays are hidden only during an explicitly enabled local
preview and return when the preview or FX setting is disabled.

REVIEW CHECKLIST BEFORE PUBLICATION
1. Confirm exact audio file, duration, source text, omissions and ad-libs.
2. Mark actual vocal phrase starts and ends on this recording; amplitude alone
   cannot identify words or distinguish a drum hit from a consonant.
3. Align source-language words using acoustic evidence and review difficult
   consonants, pickups, sustained vowels, repeated choruses and backing vocals.
4. Do not independently timestamp translated English words to unrelated sounds.
   Use phrase-level companions unless semantic word groups have been reviewed.
5. Check first entrance, every section transition, instrumental gap, last sung
   word, seek backwards, repeated pause/play and playback-rate changes.
6. Export validated draft; review all warnings; only then promote to a published
   recording-specific timeline and update the coverage audit.

JSON FORMAT
schemaVersion: 1
recording: exact manifest path, including extension
language: en | ja | zh-en | und
duration: seconds, or null while unverified
source: source/rendition/review notes
preview: boolean local opt-in
rows: [{id, start, end, ja, romaji, en, zh, pinyin, words}]
start/end: seconds, or null in drafts
words: optional language-keyed arrays of {text,start,end}; all word text must
match the corresponding line and all intervals must remain inside that line.
Drafts reject unknown schema, mismatched recording, duplicate IDs, excessive
input size, malformed numeric fields, overlap, reversed intervals, wrong
duration and inconsistent word text. Text is rendered with textContent.
